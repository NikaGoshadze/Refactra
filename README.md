# Refactra

Autonomous repository refactoring and draft pull-request automation with five sequential agent roles and two human approvals.

Current stage: Phase 1 — Architecture & Foundation. The repository contains design drafts; the application has not been implemented or deployed.

## Diagrams

- [Diagrams and editable source links](docs/diagrams/README.md)

Working architecture, contracts and decision records remain local until finalized.

The project targets small, controlled Python and React/TypeScript repositories. Public demonstrations use clearly labeled read-only replay; real execution is intended for a protected/local environment. Working behavior, tests, costs and deployment will be reported only when verified.
